Placement Portal
A Single Page Application built with Flask and Vue.js (CDN) for MAD-2.

Tech Stack
Frontend: Vue.js, Bootstrap 5, Axios
Backend: Flask, SQLite, SQLAlchemy, JWT
Tasks/Caching: Redis, Celery, Celery Beat

Setup Instructions
1.Start Redis:Ensure your local Redis server is running.
2.Start Celery Worker 
3.Start Celery Beat 
4.Run Flask App 
5.python app.py
